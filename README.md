# WINlist Web App

Mobile-first React/Vite web app that recreates the WINlist iOS SwiftUI prototype as a usable browser experience.

## Features

- WINlist-style mobile canvas with orange shell, light/dark theme, date picker, category tabs, member cards, task totals, and bottom navigation.
- Work, chores, and fitness task modes with the original avatars and task data.
- Local interactions for task checkoff, add/edit/delete, comments, poke notifications, task copy, theme switching, and layout switching.
- Local-only persistence through `localStorage`; no backend required.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Reference screenshots and copied iOS assets live in `public/assets`.
